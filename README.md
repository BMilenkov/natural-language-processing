# Natural Language Processing

A collection of Jupyter notebooks covering core NLP concepts and modern LLM techniques.

## Notebooks

| Notebook | Description |
|---|---|
| `word-embeddings.ipynb` | Exploring word vector representations and semantic similarity |
| `prompting-techniques.ipynb` | Overview of prompt engineering strategies for LLMs |
| `quantization-and-few-shot-prompting.ipynb` | Model quantization and few-shot learning in practice |
| `instructional-fine-tuning.ipynb` | Fine-tuning language models with instruction-based datasets |
| `rag.ipynb` | Retrieval-Augmented Generation (RAG) pipeline implementation |

## Requirements

- Python 3.8+
- Jupyter Notebook / JupyterLab
- Common ML libraries: `transformers`, `torch`, `sentence-transformers`, `langchain`

## Getting Started

```bash
git clone https://github.com/BMilenkov/natural-language-processing.git
cd natural-language-processing
pip install -r requirements.txt   # if available
jupyter notebook
```

## Topics Covered

- Word embeddings (Word2Vec, GloVe, etc.)
- Prompt engineering & few-shot learning
- Model quantization
- Instruction fine-tuning
- RAG with vector stores
